# Project Screenshots

Place your project screenshots here.

You can reference them in `src/content/site.ts` on any project object:

```ts
{
  slug: "cico-supervisor",
  name: "CICO Supervisor & Staff Analytics",
  screenshot: "/projects/cico.png", // <--- matches public/projects/cico.png
  ...
}
```

Recommended format: `.png` or `.webp`, 16:9 or 16:10 aspect ratio, minimum 800px width.
